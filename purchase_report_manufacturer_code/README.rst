=================================
Purchase Report Manufacturer Code
=================================
* Adds manufacturer code to purchase order and request for quotation report lines
* Adds setting toggle to PO and RFQ to choose whether to print manufacturer code on the
  report lines

Configuration
=============
* Install module
* The printed code is the product's Manufacturer Product Code

Usage
=====
* Check "Print Manufacturer Code" on a purchase order and print the PO or RFQ
