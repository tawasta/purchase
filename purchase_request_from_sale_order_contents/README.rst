================================
Purchase Request from Sale Order
================================

* Create purchase requests from existing Sale orders

Configuration
=============
No special configuration is required

Usage
=====
* Create a new Purchase Request and click `Add Sale order Contents`
* Select a sale order and click `Calculate Quantities`
* Click `Add to purchase Request` and proceed with handling the PR as usual
