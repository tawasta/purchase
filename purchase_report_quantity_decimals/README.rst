=================================
Purchase Report Quantity Decimals
=================================

* Change the number of decimals shown on purchase report product quantities

Configuration
=============
* Purchase report's decimal precision of product quantities can be set by going
  to purchase --> Configuration --> Settings and changing the value under the
  purchase_report_decimal_precision-field. The integer represents the number of
  decimals shown on product quantities.

Usage
=====
* Just install the module and print a RFQ or PO PDF
