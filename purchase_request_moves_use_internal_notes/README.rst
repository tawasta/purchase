=======================================================
Purchase Request – Stock moves only send internal notes
=======================================================
::

    PQ – Disable sending automatic e-mails from stock moves and purchases.
    Some installations would create a lot of spam to users and this module
    disables such spam.

Configuration
=============
::

    None needed

Usage
=====
::

    Go to Apps to install the module
