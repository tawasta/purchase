================================
Purchase Customer Marking Report
================================

* Prints the Customer Marking field (added by
  ``purchase_order_customer_marking``) on the Purchase Order / Request for
  Quotation PDF report, next to the Buyer field. Only shown when the field
  is filled in.

Installation
============
\-

Configuration
=============
* None needed

Usage
=====
* Fill in the Customer Marking field on a purchase order (added by
  ``purchase_order_customer_marking``) and print the Purchase Order / RFQ
  report - the value appears automatically.
